A correção já está implementada no player. O código em [code].tsx já faz exatamente o que o Cursor descreveu:

// panelWidth/Height are PHYSICAL pixels (as set in the NovaLCT / dashboard config).
// React Native layout uses LOGICAL pixels (dp), so we must divide by PixelRatio.get()
const dpr = PixelRatio.get();
const width  = panelWidth  > 0 ? Math.round(panelWidth  / dpr) : deviceW;
const height = panelHeight > 0 ? Math.round(panelHeight / dpr) : deviceH;

O que isso resolve:

NovaLCT → cadastra 168×168 no dashboard (pixels físicos reais da placa)
Player recebe 168, divide por PixelRatio.get() (1,5 no T10 Plus) → renderiza em 112 dp
112 dp × 1,5 = 168 px físicos → encaixa perfeitamente na placa, sem corte
