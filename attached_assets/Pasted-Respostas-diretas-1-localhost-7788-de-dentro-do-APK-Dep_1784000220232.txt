Respostas diretas:

1) localhost:7788 de dentro do APK?
Depende do bind do serviço NovaStar.

Escuta em 0.0.0.0 ou 127.0.0.1 → http://127.0.0.1:7788 funciona no APK
Escuta só no IP LAN → localhost falha; use o IP da placa
O ViPlex no PC usar o IP LAN não prova loopback. Confirme no T50:

adb shell "ss -lntp | grep 7788"
adb shell "curl -s -X POST http://127.0.0.1:7788/api/v1/login -H \"Content-Type: application/json\" -d \"{\\\"userName\\\":\\\"admin\\\",\\\"password\\\":\\\"123456\\\"}\""
Se vier token → use 127.0.0.1 no APK (melhor).

2) Se precisar do IP LAN?
import * as Network from "expo-network";
const ip = await Network.getIpAddressAsync();
Ordem no helper: tentar 127.0.0.1 → se falhar, IP LAN. Cachear baseUrl + token.

3) CORS / cleartext / bloqueio?
Item	Situação
CORS	Não atrapalha (não é browser)
INTERNET	Já tem no app
HTTP cleartext	Pode bloquear — Android 9+ bloqueia HTTP por padrão
No app.config.js atual não tem usesCleartextTraffic: true. Sem isso (ou network security config pra localhost/LAN), o fetch pra http://…:7788 tende a falhar com Network Error.

Obrigatório no próximo build: liberar cleartext pelo menos pra 127.0.0.1 / localhost / LAN.
