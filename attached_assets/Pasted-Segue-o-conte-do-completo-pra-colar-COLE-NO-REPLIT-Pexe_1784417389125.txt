B1) Detectar duplicatas Pexels
Agrupar por “chave Pexels” extraída do nome:

function pexelsKey(name: string): string | null {
  const v = name.match(/^pexels-video-(\d+)/);
  if (v) return `video:${v[1]}`;
  const p = name.match(/^pexels-(\d+)-/);
  if (p) return `photo:${p[1]}`;
  return null;
}
Para cada chave com 2+ itens: manter o de menor id (primeiro importado), marcar os outros para delete.
