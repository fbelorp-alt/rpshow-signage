A) Transições entre cenas — pack V3
Estender Scene["transition"]:

type SceneTransition =
  | "none"
  | "fade"          // dissolver
  | "slideLeft" | "slideRight" | "slideUp" | "slideDown"
  | "zoom"
  | "wipeLeft" | "wipeRight"   // cortina
  | "circle"                   // iris / círculo
  | "colorBlock";              // bloco de cor (preenche e revela)
Campos novos na Scene:

transitionMs?: number;        // 300–2000 (slider; defaults 500)
transitionDir?: "left" | "right" | "up" | "down"; // onde fizer sentido
transitionColor?: string;     // só colorBlock — default "#0d1117"
UI obrigatória — ícone entre clips na timeline (estilo Canva):

Entre cena N e N+1: botão circular pequeno
Clique abre popover Transições com grid de presets (ícone + nome)
Slider duração (0.3s–2.0s)
Direção (4 setas) quando o preset usar
Botão “Aplicar a todas as cenas”
Badge na timeline mostra inicial do tipo (F / S / Z / W / C…)
Obrigatório funcionar em 3 lugares iguais:

Preview no editor (switchScene / CSS ou canvas overlay)
captureAsVideo → MP4/WebM (applyTransition no canvas 2D)
Popover da timeline + aba Trans. do painel direito
Se o preset não rodar no export MP4, não entregue (é half-fix).

Implementação sugerida no applyTransition (canvas 2D):

fade / slides → já existem; completar slideUp/Down
wipe → ctx clip progressivo horizontal/vertical
circle → clip circular crescendo do centro
colorBlock → preenche com transitionColor até cobrir, depois revela próxima cena
Preview CSS: keyframes equivalentes (beTransWipe*, beTransCircle, beTransColorBlock).
