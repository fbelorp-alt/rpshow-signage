═══ FIX OBRIGATÓRIO — TOCAR NO TB10 ═══

1) WebView YouTube SEMPRE:
   - allowsFullscreenVideo={false}
   - mediaPlaybackRequiresUserAction={false}
   - allowsInlineMediaPlayback={true}
   - javaScriptEnabled / domStorageEnabled / thirdPartyCookiesEnabled
   - androidLayerType="hardware"  (se ainda crashar no TB10, testar "software" só no path YT)
   - Manter HTML wrapper + baseUrl https://app.rpshow.com.br + referrerpolicy
   - fs=0, playsinline=1, mute=1 no embed (autoplay exige mute no WebView)
   - SEM allowfullscreen no iframe

2) Embed estável no TB10 (toYouTubeEmbedUrl / buildYouTubeHtml):
   - Preferir youtube-nocookie.com
   - Playlist: list= / videoseries — NÃO loop=1&playlist=videoId
   - Single: loop=1&playlist=videoId ok
   - enablejsapi=1
   - NÃO injetar JS que force fullscreen / UI hacks pesados

3) Montagem segura no TB10:
   - Não montar WebView YT no mesmo frame do boot do player
   - Delay curto (300–800ms) depois do item virar youtube → aí set ytWebMounted true
   - key completa:
     key={`web-yt-${slotIndex}-${playState.key}-${playlistId ?? "p"}-${publishedAt ?? "t"}`}

4) Crash NÃO mata o app + RETRY de play:
   - onRenderProcessGone / onContentProcessDidTerminate → return true / engolir
   - Log [YT-TB10-CRASH] attempt=N
   - Unmount (null) → wait 500–1000ms → remount MESMO item (retry)
   - Máx 2 retries; se falhar → advance/skip, heartbeat continua
   - Plugin nativo WebViewClient.onRenderProcessGone return true se prop JS fraca
   - NUNCA BackHandler.exitApp() por YouTube

5) Fallback Intent (OBRIGATÓRIO tentar se WebView falhar 2x):

   - Documentar na resposta se o TB10 tem ou não o app YouTube instalado
